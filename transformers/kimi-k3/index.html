What Kimi K3 is

Kimi K3 is Moonshot AI's mixture-of-experts model, 2.78T parameters by the manifest's count, with a context of 1,048,576 tokens. Most of its 93 layers are not softmax attention. The Depth strip shows 69 Kimi Delta Attention (KDA) layers, a gated linear-attention recurrence that keeps a fixed-size state, and 24 Multi-head Latent Attention (MLA) layers, at every fourth layer and the last. Three recurrent layers to one attention layer: most of the model's memory does not grow with the context.

The page records layers 1–4, the first group of three KDA layers and one MLA layer, on the 8-token prompt “Paris is in France. Paris is in”. Weights were read by HTTP range requests from the checkpoint, only the experts each router picked, and run in float32 on the CPU. Layers 5–93 and the LM head were not run, so the page shows no next token. The KDA computation is the page's own recurrent implementation, checked against flash-linear-attention's reference kernels.

From linear attention to the delta rule

Softmax attention keeps every past key and value and compares each new query with all of them. Linear attention drops the softmax. The output then becomes a product with one running matrix, a memory S that maps keys to values and is updated once per token:

St​=St−1​+vt​kt⊤​,ot​=St​qt​

Schlag et al. read this as a fast-weight memory, and saw its flaw: it only adds. Writing a new value under a key that already holds one blends the two. The delta rule writes only the correction. It reads what the memory currently returns for kt​ and moves that towards vt​ with a strength βt​∈(0,1):

St​=St−1​+βt​(vt​−St−1​kt​)kt⊤​=St−1​(I−βt​kt​kt⊤​)+βt​vt​kt⊤​

With a unit-length key and βt​=1 it replaces what S held along kt​. DeltaNet made this trainable in parallel over a sequence, and Gated DeltaNet added a forget gate, one decay rate per head. KDA's gate is finer, one forget rate per key channel, αt​∈(e−5,1)128:

St​=St−1​diag(αt​)(I−βt​kt​kt⊤​)+βt​vt​kt⊤​,ot​=St​qt​/128​

Inside a KDA layer

Each of the 96 heads computes q, k and v of 128 dimensions. Each passes through a 4-tap short convolution, in which every channel mixes its own last four inputs, and a SiLU; q and k are then L2-normalised. The forget gate comes from a low-rank projection, logαt​=−5σ(⋅)∈(−5,0), and the write strength from βt​=σ(xt​Wb​). The output passes through a per-head RMSNorm and a sigmoid gate before WO​.

The State S column splits one token's update into its four terms: the old state, its decay ⋅α, the erase −β(Sk)k⊤ and the write +βvk⊤. At the default, layer 3, head 76, the second “ is”, the state already returns 0.92 times the length of v at cosine 0.93 before writing. The delta rule therefore adds only a correction, where a purely additive memory would have added all of v a second time.

Unrolling the recurrence writes the output as a weighted sum of past values, which the Token mixing A matrix draws:

ot​=i≤t∑​Ati​vi​,Ati​=βi​ki⊤​Gi+1​⋯Gt​qt​/128​,Gj​=diag(αj​)(I−βj​kj​kj⊤​)

There is no softmax, so a row need not sum to 1, and a weight can be negative where a later key overwrote an earlier one. The page computes A in the browser from the recorded q, k, v, α and β.

A fixed state against a growing cache

A KDA layer carries 96 states of 128 × 128 plus its convolution buffers, 1,683,456 numbers whatever the length. Layer 4's MLA caches a 512-dimensional latent and a 64-dimensional shared key per token, 576 numbers; standard multi-head attention with the same heads would cache 30,720 per token. The chart in the MLA layer's Cache column puts the crossover at 2,923 tokens. At the full 1.05M-token context the whole model holds 14.6B numbers, 99 % of them in the 24 MLA caches.

The MLA layers keep the exact retrieval that a fixed state cannot. In layer 4, head 23 puts 0.96 of the last “ in”'s weight on “ France”, the word to copy. Kimi K3 applies no RoPE anywhere: the MLA layers know nothing of order, which comes from the KDA layers' convolutions and decays. Its report credits this for extending to a 1M-token context without retuning any positional encoding.

Attention residuals and latent experts

Usually every sublayer adds its output to one running residual sum. With attention residuals, each sublayer instead reads a softmax mix of the embedding, the sum of every finished 12-layer block, and its own block's partial sum, weighted by a learned query:

w=softmaxn​(RMSNorm(cn​)⋅qℓ​),x=n∑​wn​cn​

Layers 1–4 all sit in the first block, so the bars in the Residual column choose between the embedding and the layers so far. In layer 2 the attention input takes between 11.2 % and 35.3 % from the embedding, depending on the token.

The Latent MoE view shows the experts. A sigmoid router scores 896 routed experts and picks 16, adding a load-balancing bias for the choice but weighting by the renormalised scores. The input is projected down from 7,168 to a 3,584-dimensional latent, the 16 experts work there, and their weighted sum is normalised and projected back up, beside two always-on shared experts:

y=Wup​RMSNorm(e∈top-16∑​we​Ee​(Wdown​x))+Shared(x)

Expert weights are stored in MXFP4, 4-bit values with one shared scale per 32. The 8 prompt tokens picked 86, 81 and 67 distinct experts in layers 2–4, and only those were read. Layer 1 has a dense MLP instead, 7,168 → 33,792 → 7,168, with Moonshot's SiTU gate.

Where it came from

Katharopoulos et al. (2020) showed that a transformer without the softmax is an RNN. Schlag et al. (2021) connected it to fast-weight programmers and brought in the delta rule. Yang et al. made DeltaNet trainable in parallel (2024) and added gating in Gated DeltaNet. Kimi Linear (2025) introduced KDA, with its channel-wise gate, and the 3:1 hybrid with MLA; at matched training it outperformed full MLA while cutting the KV cache by up to 75 %. Attention Residuals (2026) replaced fixed residual sums with attention over earlier layers. Kimi K3 (2026) combines these at 2.8T parameters with Stable LatentMoE.

MLA itself comes from DeepSeek-V2; see the MLA tab. The LinA tab (RWKV-7) shows another recurrence with a delta-style state update.
