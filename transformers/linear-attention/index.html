What linear attention is

Softmax attention keeps every past key and value. A decoder's KV cache grows by one entry per token, and each new query is compared with all of them. Linear attention drops the softmax so that the sum over the past folds into one matrix. If a token's output is ot​=∑i≤t​(ki⊤​qt​)vi​, then St​=∑i≤t​vi​ki⊤​ can be updated one token at a time and read with the query:

St​=St−1​+vt​kt⊤​,ot​=St​qt​

The model becomes a recurrent network whose state has a fixed size, whatever the length of the prompt. RWKV-7 is such a network. This page records RWKV-7 0.1B (g1) on The capital of France is: five tokens through all 12 blocks of width 768, each with 12 heads of 64. The most likely next token is Paris, with probability 0.3204. Each head carries one 64 × 64 state from token to token, and there is no KV cache.

Token shift and the six projections

RWKV-7 has no position input. The order of the tokens reaches the model through the recurrence and through token shift: before projecting, each block mixes every token's input with the previous token's, with a learned per-channel weight μc​ for each projection c:

x^c​=xt​+(xt−1​−xt​)⊙μc​,c∈{r,w,k,v,a,g}

The bank then makes six vectors per token, each 768 wide (12 heads of 64): the receptance r, which reads the state as a query reads keys; the key k and value v; the decay w; the in-context learning rate a; and the output gate g. r, k and v are full 768 × 768 projections. w, a and g are low-rank, passing through 64, 64 and 128 dimensions. Block 1 also applies an extra LayerNorm, ln0, to the embedding.

The state update

Each head keeps a state S, a 64 × 64 matrix whose rows index value channels and whose columns index key channels. Every token changes it in three steps, which the WKV state update popup names decay, delta rule and write:

St​=St−1​(diag(wt​)−κ^t​(κ^t​⊙at​)⊤)+vt​k~t⊤​,ot​=St​rt​
  • Decay. Column j of S is multiplied by wj​=exp(−e−0.5σ(zj​)), where z=w0​+tanh(x^w​Aw​)Bw​. It lies between 0.545 and 1 and depends on the token, so the model chooses per channel how quickly to forget.
  • Delta rule. Sκ^ is what the state returns for the unit key κ^=normalize(k⊙kk​). The update removes a share of it set by a=σ(a0​+x^a​Aa​Ba​), between 0 and 1, so a new value can replace an old one instead of piling on top of it.
  • Write. The value is added along the key k~=k⊙(1+(a−1)⊙ka​), rescaled per channel by a.

Without the decay and the delta rule this would be plain linear attention. The State S card draws the chosen head's state after each token, and it stays 64 × 64: 4,096 numbers per head and 49,152 for all 12 heads, whatever the prompt length. Besides the state, the model carries only the two token-shift vectors from one token to the next.

The recurrence as a mixing matrix

Unrolling the recurrence writes each output as a weighted sum of earlier values, the same shape as attention. With Gt​=diag(wt​)−κ^t​(κ^t​⊙at​)⊤,

ot​=i≤t∑​At,i​vi​,At,i​=k~i⊤​Gi+1​Gi+2​⋯Gt​rt​,At,t​=k~t​⋅rt​

The Token mixing A panel builds this matrix in three stages. The first, k~i​⋅rt​, ignores decay and the delta rule; the second applies the decay only; the third is the actual A. The first two are comparisons that the model never computes. Unlike a softmax attention matrix, A is not normalised and its entries can be negative (drawn orange), and no token reads a later one. Multiplying A by the values reproduces the recurrence's output to within 7.65×10−6.

Normalisation, bonus, gate and channel mix

Each head's output goes through a GroupNorm with ε=64⋅10−5. A bonus term (r⋅(k~⊙rk​))v then adds the current token's own value directly, skipping the state. The sum is multiplied by the gate g and projected back to 768 by Wo​. In blocks 2 to 12 the value is first pulled towards block 1's value, v←v+(v1​−v)⊙σ(v0​+x^v​Av​Bv​); the page marks this v-first.

Each block ends with a channel mix, RWKV's feed-forward layer. It has its own token shift and a squared ReLU, Wv​relu(Wk​x^)2, from 768 to 3072 and back. The output matrix that scores the 65,536 vocabulary entries is separate from the embedding.

Where RWKV-7 came from

Katharopoulos et al. (2020) showed that attention with a kernel feature map in place of the softmax is a recurrent network with a matrix state. Schlag, Irie and Schmidhuber (2021) read that state as fast weights written by the network, and replaced its purely additive write with the delta rule, which corrects what the memory returns for a key. RWKV (Peng et al., 2023) built large recurrent language models around a per-channel time decay; Eagle and Finch (RWKV-5 and RWKV-6) gave it matrix-valued states and a decay that depends on the token. Yang et al. trained delta-rule linear attention in parallel over the sequence (DeltaNet) and later added a decay gate to it (Gated DeltaNet).

RWKV-7 (2025) generalises both lines: its decay and its in-context learning rate are vectors, and the key it removes along differs from the key it writes. The DeltaA tab continues with Kimi Delta Attention, and the Mamba hybrid tab draws a state-space recurrence as a mixing matrix in the same way.
