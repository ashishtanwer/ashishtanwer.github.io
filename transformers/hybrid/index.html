Why mix attention and state spaces

Attention can read any earlier token exactly, but it keeps a key and a value for every one of them. A state-space model such as Mamba reads the past only through a state of fixed size, which costs the same at any length but has to compress what it keeps. A hybrid stacks mostly state-space blocks and calls attention only now and then.

The Mamba2 mixer

Each Mamba2 mixer projects its normalised input with Win​ (2048 → 8512) into five parts, in this order: a gate z (4096), the input x (4096), B (128), C (128) and a step size Δ for each of the 64 heads. A causal convolution of width 4 followed by SiLU mixes x, B and C with the three tokens before them.

Each head h owns 64 channels of x and a 64 × 128 state s. With a learned Ah​<0, the scan is

st​=eΔt​Ah​st−1​+Δt​xt​Bt⊤​,yt​=st​Ct​+Dh​xt​

Bt​ decides how the token is written into the state and Ct​ how the state is read out. Both are computed from the token, which is what makes the model selective. The step size Δt​=max(0.001,softplus(dt+b)) sets the balance: a large Δ forgets more of the old state and writes more of the new token. In Mamba2 the decay eΔt​Ah​ is one number per head and token, shared by all 64 channels and 128 state coordinates.

The Gate · RMSNorm · Wout step multiplies the scan output by SiLU(z), normalises it over its 4096 coordinates and projects it back to 2048. The state of one mixer is 64 heads × 64 channels × 128 = 524,288 numbers, whatever the length of the prompt.

The scan as a mixing matrix

Unrolling the scan gives every output as a weighted sum of earlier inputs:

yt​=s≤t∑​Mt,s​xs​+Dxt​,Mt,s​=Δs​eA(Δs+1​+⋯+Δt​)(Ct​⋅Bs​)

C plays the part of a query, B of a key and x of a value, and the decay becomes a causal mask that shrinks with distance. Dao and Gu call this equivalence structured state-space duality: the same layer can run as a recurrence, token by token, or as attention-like matrix products over chunks of the sequence.

The State-space mixing panel builds M in three stages: C⋅B⊤, then the decay mask L(Δ,A), then M=L∘CB⊤. The page computes it in the browser from the recorded B, C, Δ and A. Unlike softmax weights, its entries are not normalised and can be negative (drawn orange). The state the page shows is rebuilt token by token and matches the model's own chunked scan to within 7.63×10−6.

The shared transformer

The shared block reads the concatenation [x;e0​] of the current hidden state and the original token embedding, 4096 wide, normalised with RMSNorm. Its 32 heads of 128 dimensions rotate Q and K with RoPE and scale the scores by 1/8, which is 1/64​ although the heads are 128 wide. A Gated MLP, GELU(g)⊙u from 2048 to 8192 and back, follows.

The six calls share these weights but do not compute the same function. Each adds its own low-rank adapter (LoRA, rank 128) to the shared Q, K, V and MLP input projections, and each ends with its own 2048 × 2048 Linear layer. There is no residual inside the shared block. Its output t joins only the input of the same block's Mamba mixer:

x←x+Mamba(RMSNorm(x+t))

So only the Mamba output enters the residual stream. The attention still keeps keys and values for every token, but at 6 of the 38 blocks rather than all of them.

Where hybrids came from

Structured state spaces began with S4 (Gu, Goel and Ré), a linear recurrence with a fixed, carefully initialised state matrix that can be computed as one long convolution. Mamba (Gu and Dao, 2023) made Δ, B and C depend on the token. That rules out the convolution but lets the model choose what to keep, and a parallel scan computes it quickly. Mamba-2 (Dao and Gu, 2024) restricted A to one number per head and showed the duality with attention.

Jamba (2024) interleaved attention and Mamba layers and added mixture-of-experts MLPs. Zamba (2024) kept a stack of Mamba blocks and called one shared attention block every few blocks; the Zamba2 report moved to Mamba2 blocks and added the per-call LoRA adapters. The LinA tab draws RWKV-7, a recurrence with a matrix state and a delta rule, as a mixing matrix in the same way, and the Attention explainer's Mamba tabs take the selective scan and its duality further.
