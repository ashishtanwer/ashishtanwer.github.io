What Mamba is

Attention keeps every past key and value and compares each new token with all of them. A state-space model instead carries a fixed-size state forward and updates it once per token, so each step costs the same however long the sequence grows. Earlier state-space layers updated the state the same way whatever the token, and they fell behind attention on language, where what to keep depends on what was just read. Mamba (Gu and Dao, 2023) makes the update depend on the token: a selective state space. The paper reports a Mamba-3B that outperforms Transformers of the same size and matches Transformers twice its size in language modelling.

The page records Mamba 130M, all 24 layers, on three short prompts. Each layer's mixer has 1,536 channels that scan the sequence independently; for every layer the page shows the 8 channels whose output draws most on earlier tokens.

A state space, discretised

Each channel holds a state of 16 numbers, one per diagonal entry of a decay matrix A. In continuous time the state follows h′(τ)=Ah(τ)+Bx(τ) and is read out by y=Ch. With a step size Δ, Mamba turns this into a recurrence over tokens:

ht​=eΔt​A⊙ht−1​+Δt​Bt​xt​,yt​=Ct​⋅ht​+Dxt​

An​=−eAlog,n​ is negative, so eΔt​An​ lies between 0 and 1: the share of state entry n that survives step t. D is a skip connection from input to output. The A box on the card lists the channel's 16 rates and their survival at the selected token.

Selection

In S4 and its successors Δ, B and C were learned constants, so the whole layer was a fixed convolution over the sequence. Mamba computes them from each token through a projection called x_proj:

Bt​=WB​xt​,Ct​=WC​xt​,Δt​=softplus(WΔ​Wr​xt​+bΔ​)

Bt​ says what token t writes into the state and Ct​ how it reads the state; both are 16-dimensional and shared by all 1,536 channels of the layer. Δt​ goes through a rank-48 bottleneck Wr​, is different for every channel and acts as a gate: a large Δt​ writes the token strongly and decays what was there, a small one lets the state pass the token by. The B, C and Δ boxes list them for every token.

Input-dependent parameters rule out the convolution trick, so Mamba computes the recurrence with a hardware-aware parallel scan that keeps the expanded state in fast on-chip memory. The recording runs the plain sequential loop, which gives the same numbers.

The scan as an attention-like matrix

Unrolling the recurrence, each output is a weighted sum of the channel's past inputs, so the scan is a causal matrix M applied to x, with C in the query's place, B in the key's and the channel's x as the value:

Mts​=n=1∑16​Ct​[n]eAn​∑s<r≤t​Δr​Δs​Bs​[n](s≤t),yt​=s≤t∑​Mts​xs​+Dxt​

Ali et al. (2024) used this view to read the hidden attention of Mamba models. The Scan M view draws the recorded channel's matrix; Δ·C·B, no decay leaves the decay out. The decay sits inside the sum over the 16 state entries, each with its own rate, so M is not the second matrix times one decay per distance. There is no softmax: weights are signed and need not sum to one. The page computes M from the captured Δ, A, B and C, and it agrees with the recurrence to 3×10−5.

The Mamba block

Mamba has no attention and no separate MLP; one block, preceded by an RMSNorm, repeats 24 times:

  • in_proj maps the 768-dimensional input to two 1,536-wide streams, x and z.
  • x passes a causal depthwise convolution of 4 taps and a SiLU; x_proj then selects Δ, B and C from it, and the scan runs.
  • The scan output y is multiplied by SiLU(z), a gate that went around the scan, and out_proj maps 1,536 channels back to 768.

There are no position embeddings: order enters through the short convolution and through the scan, which only carries information forward. The Output column is the block's mixer output before the residual add.

Where it came from

S4 (Gu et al., 2021) made long state-space layers trainable with a structured A and a fixed convolution kernel; H3 (2022) and Hyena (2023, the Hyena tab) added data-dependent gates around long convolutions. Mamba made the state update itself selective. Mamba-2 (2024) restricted A to one scalar per head, which turns the matrix above into a masked form of linear attention and allows a faster algorithm: see the Mamba-2 tab, and the Linear and RetNet tabs for the attention side of the same family.
